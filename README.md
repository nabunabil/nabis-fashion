# 🛍️ NABIS FASHION

A modern full-stack e-commerce web application developed as part of my Placement Project at Ulster University.

## ✨ Features

- 🔐 User Authentication & Authorization
- 🛒 Shopping Cart Functionality
- 📦 Product Management
- 🏷️ Category & Variant Management
- ⭐ Product Reviews & Ratings
- 💳 Stripe Payment Integration
- 📄 PDF Invoice Generation
- 📧 Email Notifications
- ☁️ Cloudinary Image Uploads
- 👨‍💼 Admin Dashboard

---

- Tailwind CSS

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/nabunabil/nabis-fashion.git
```

### Frontend

```bash
cd client
npm install
npm run dev
```

### Backend

```bash
cd server
npm install
npm run dev
```
